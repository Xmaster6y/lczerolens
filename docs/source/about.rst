About lczerolens
================

``lczerolens`` provides PyTorch interoperability and chess-analysis evidence
for lc0-family networks. Start with :doc:`start`, run the :doc:`tutorials`, and
use :doc:`api/index` when you need exact signatures.

Related projects
----------------

* `Leela Chess Zero <https://lczero.org/>`_
* `python-chess <https://python-chess.readthedocs.io/>`_
* `TensorDict <https://docs.pytorch.org/tensordict/>`_

Interpretability methods are external integrations rather than core
lczerolens APIs.
